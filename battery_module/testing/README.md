# Testiranje

Ta mapa je namenjena zapisu in organizaciji testov za modularni baterijski sistem FARMBEAST.

Predlagani tipi testov:

- test posameznih celic,
- test enega 7S1P modula,
- test polnjenja in praznjenja,
- test BMS zaščit,
- test več modulov v paraleli,
- test hot-swap / precharge zaščite,
- test segrevanja,
- test na robotu.

Testi se naj izvajajo postopno, od posamezne celice do celotnega sistema.
